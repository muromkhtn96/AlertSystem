04. Phan Tich Bang Excel

Buoc 1: Mo file outcomes.csv

Excel → Data → From Text/CSV → chon file _outcomes.csv

Buoc 2: Tao cot Win/Loss

Cot moi "Win" (cot R):
=IF(OR(I2="STRONG_REACT", I2="WEAK_REACT"), 1, 0)

Cot moi "Loss" (cot S):
=IF(OR(I2="FAILED", I2="BROKEN"), 1, 0)

Buoc 3: Tinh Win Rate theo Score Range

Premium (≥120):
=COUNTIFS(D:D,">=120", R:R, 1) / COUNTIFS(D:D,">=120", R:R,">=0")

Level 1 (85-119):
=COUNTIFS(D:D,">=85", D:D,"<120", R:R, 1) / COUNTIFS(D:D,">=85", D:D,"<120", R:R,">=0")

Buoc 4: Pivot Table — Win Rate theo tung yeu to

Theo Session

Row: session → Values: AVG(Win)
Tim session nao co win rate cao/thap nhat

Theo Regime

Row: regime → Values: AVG(Win)
Ranging co tot hon Trend khong?

Theo Pattern

Row: pattern → Values: AVG(Win)
Pinbar co thuc su tot hon Engulfing?

Theo Test Count

Row: test_count → Values: AVG(Win)
Xac nhan mitigation: test 3+ co that su yeu?

05. Phan Tich Bang Python

Script phan tich co ban

import pandas as pd

# Doc data
outcomes = pd.read_csv('EURUSD_PERIOD_H1_outcomes.csv')
zones    = pd.read_csv('EURUSD_PERIOD_H1_zones.csv')

# Them cot win/loss
outcomes['win'] = outcomes['outcome'].isin(['STRONG_REACT','WEAK_REACT']).astype(int)
outcomes['loss'] = outcomes['outcome'].isin(['FAILED','BROKEN']).astype(int)

# === 1. WIN RATE THEO SCORE RANGE ===
bins = [0, 40, 60, 85, 120, 200]
labels = ['Hidden', 'LV3', 'LV2', 'LV1', 'Premium']
outcomes['level'] = pd.cut(outcomes['score_at_test'], bins=bins, labels=labels)
print(outcomes.groupby('level')['win'].agg(['mean','count']))

# === 2. WIN RATE THEO SESSION ===
print(outcomes.groupby('session')['win'].agg(['mean','count']).sort_values('mean', ascending=False))

# === 3. WIN RATE THEO REGIME ===
print(outcomes.groupby('regime')['win'].agg(['mean','count']))

# === 4. WIN RATE THEO TEST COUNT (MITIGATION) ===
print(outcomes.groupby('test_count')['win'].agg(['mean','count']))

# === 5. WIN RATE THEO PATTERN ===
print(outcomes.groupby('pattern')['win'].agg(['mean','count']).sort_values('mean', ascending=False))

# === 6. OPTIMAL SCORE THRESHOLD ===
for threshold in range(80, 160, 10):
    subset = outcomes[outcomes['score_at_test'] >= threshold]
    if len(subset) > 5:
        wr = subset['win'].mean()
        n = len(subset)
        print(f"Score >= {threshold}: Win Rate = {wr:.1%} (n={n})")

Script nang cao — Tim weight toi uu

# === 7. TUONG QUAN TUNG YEU TO VOI OUTCOME ===
# Gop zones + outcomes
merged = outcomes.merge(zones, on='rp_id', suffixes=('','_zone'))

# Correlation matrix
factors = ['reaction_pips','volume_ratio','width_atr_ratio','final_score_zone']
for f in factors:
    if f in merged.columns:
        corr = merged[f].corr(merged['win'])
        print(f"{f}: correlation with win = {corr:.3f}")

# === 8. WICK FILTER HIEU QUA? ===
wf = outcomes.merge(zones[['rp_id','has_wick_filter']], on='rp_id')
print(wf.groupby('has_wick_filter')['win'].agg(['mean','count']))

# === 9. ORDER BLOCK vs SWING ===
ob = outcomes.merge(zones[['rp_id','is_order_block']], on='rp_id')
print(ob.groupby('is_order_block')['win'].agg(['mean','count']))

# === 10. BODY TEST vs WICK TEST ===
tests = pd.read_csv('EURUSD_PERIOD_H1_tests.csv')
test_quality = tests.groupby('rp_id')['is_body_test'].apply(
    lambda x: (x=='BODY').mean()
).reset_index(name='body_ratio')
tq = outcomes.merge(test_quality, on='rp_id')
tq['body_dominant'] = tq['body_ratio'] >= 0.5
print(tq.groupby('body_dominant')['win'].agg(['mean','count']))
